# P0.2.2 — Real-image quality distribution + calibration

Status: IMPLEMENTED — execution pending authorized dataset + real SCRFD artifacts.

## Objective
Calibrate the recognition quality gate from real, person-disjoint images without inventing universal thresholds. Quality gating is upstream of recognition and must be evaluated for both genuine retention and false-match risk.

## Required input
JSONL records produced by the real SCRFD pipeline. Each record must contain:
- `person_id`
- `split`: calibration | validation | locked_test
- `camera_id` / `device_id`
- `condition` (frontal, pose, blur, low_light, occlusion, small_face, etc.)
- deterministic quality features: `face_width`, `face_height`, `bbox_confidence`, `blur_score`, `brightness`, `yaw`, `pitch`, `roll`
- optional `recognition_quality`
- optional `embedding_path` or embedding reference for downstream pair evaluation

No person may occur in more than one split.

## Calibration protocol
1. Compute distributions by split, device/camera and condition.
2. Select thresholds on calibration/validation only.
3. Produce ACCEPT / REVIEW / REJECT decisions with stable reason codes.
4. Evaluate locked test exactly once per candidate configuration.
5. Report acceptance/rejection rate and, when pair labels are available, FMR/FNMR/TAR at fixed low-FAR operating points.
6. Do not tune recognition similarity threshold and quality threshold in the same optimization loop.

## Acceptance
- deterministic and reproducible output;
- no person leakage across splits;
- every rejected sample has reason codes;
- calibration artifact contains config version, model versions, dataset manifest hash and threshold values;
- locked-test metrics are separated from validation metrics.

## Next
After real quality calibration, proceed to empirical liveness/FAS calibration while keeping recognition thresholding separate.
