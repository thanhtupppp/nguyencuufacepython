# P0.4.24 — Artifact Receipt and ONNX Contract Verification

Status: IMPLEMENTED — execution blocked on obtaining exact artifact bytes and completing license review.

## Objective
Turn the official InsightFace v0.7 detector/recognizer candidates into reproducible benchmark inputs without treating a downloadable model as production-approved.

## Locked candidates
- SCRFD `det_10g.onnx` from official `buffalo_l` v0.7 package.
- ArcFace `w600k_r50.onnx` from official `buffalo_l` v0.7 package.

## Verification sequence
1. Download the exact official release asset/package.
2. Record package SHA-256 and exact file SHA-256 after extraction.
3. Record model ID/version/source URL/publisher/license/commercial-use decision.
4. Load each ONNX graph with ONNX Runtime CPU.
5. Record input/output names, shapes, dtypes, dynamic/static dimensions.
6. Verify SCRFD produces boxes and five landmarks on a deterministic fixture.
7. Verify ArcFace accepts 112x112 aligned RGB/BGR contract as implemented and produces 512-D finite output.
8. Apply project L2 normalization contract and record norm/error tolerance.
9. Generate a model receipt containing all above values.

## Safety / licensing gate
The official InsightFace repository states that code is MIT but pretrained models/training data are governed separately; open-source recognition model packages require separate licensing for commercial use. Unknown or research-only status is not production approval.

## Acceptance
- Exact artifact SHA-256 values are pinned.
- ONNX contracts are captured from the actual files, not copied from documentation.
- Deterministic CPU smoke test passes.
- License/provenance decision is explicit.
- Receipt is reproducible by another operator.

## Next
Use the verified SCRFD artifact on an authorized real-image dataset for P0.2.2 quality calibration. Only after the ArcFace receipt is also complete should real embedding/vector benchmarks resume.
