# P0.4.26 — Artifact Acquisition Hardening

Status: IMPLEMENTED — execution pending.

## Objective
Harden the official InsightFace v0.7 artifact acquisition path before any model bytes are admitted to benchmarking.

## Scope
- Download only the pinned official `buffalo_l.zip` URL.
- Enforce the pinned package byte size.
- Reject unsafe ZIP members (absolute paths, `..` traversal, unexpected duplicate model entries).
- Extract only the two locked ONNX files.
- Write model files atomically into the artifact directory.
- Emit a receipt containing package and extracted-file SHA-256 values computed from actual bytes.

## Verification
Run:

```bash
python tools/acquire_insightface_v07_models.py --output models/artifacts/buffalo_l --receipt models/artifacts/buffalo_l_receipt.json
```

Negative tests must prove unsafe ZIP members are rejected before extraction and partial output is not accepted as a valid artifact set.

## Acceptance
- Unit tests cover ZIP path traversal and duplicate/ambiguous locked members.
- Extraction is atomic from the operator's perspective.
- Existing valid artifacts are not silently replaced by a failed acquisition.
- Receipt hashes are always computed from the exact extracted bytes.
- No model is marked production-approved by this task.
