# P0.4.23 — Model Artifact Acquisition Matrix

Status: IMPLEMENTED — candidate evaluation pending verified artifacts.

## Objective
Create a reproducible gate for selecting the actual SCRFD detector and ArcFace recognition artifact used by the project. Availability or speed alone must never change the architecture.

## Required candidate record
Each candidate must record:
- component: detector | recognition
- model_id
- model_version
- artifact_filename
- input_contract
- output_contract
- SHA-256
- source_url
- publisher
- license
- commercial_use: allowed | restricted | unknown
- runtime: onnxruntime_cpu | cuda | directml | android | other
- notes

## Mandatory verification
1. Artifact bytes are available from an authoritative source.
2. SHA-256 is computed from the exact artifact and pinned.
3. ONNX graph loads successfully on the supported CPU runtime.
4. Detector contract exposes expected face boxes/landmarks.
5. Recognition contract accepts 112x112 aligned input and produces 512-D embeddings for the locked ArcFace baseline.
6. Output is finite and L2-normalized by the project contract.
7. License/provenance is explicitly reviewed. Unknown or non-commercial-only weights are not production-approved.

## Research baseline
Keep InsightFace/SCRFD + ArcFace as the baseline. Alternatives may be added only as benchmark candidates with identical dataset, alignment, quality gate, and evaluation protocol.

## Acceptance
- At least one detector candidate and one recognition candidate pass provenance + runtime verification.
- No placeholder SHA/license/source values remain for a benchmark-approved artifact.
- A reproducible model receipt records model ID/version/SHA/runtime/input/output contracts.

## Important license rule
InsightFace source code is MIT, but official documentation states pretrained models/training data are subject to separate licensing and commercial recognition model licensing may require contacting InsightFace. Therefore model approval is independent of repository-code licensing.
