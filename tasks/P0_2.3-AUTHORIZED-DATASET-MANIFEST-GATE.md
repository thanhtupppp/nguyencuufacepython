# P0.2.3 — Authorized Dataset Manifest Gate

Status: IMPLEMENTED — execution pending authorized dataset.

## Objective
Remove the remaining data-side blocker for P0.2.2 by defining a machine-verifiable manifest for authorized face images and enforcing person-disjoint calibration/validation/locked-test splits before SCRFD quality observations are generated.

## Why
P0.2.2 cannot produce a defensible threshold without knowing that every image is authorized, uniquely identified, bound to one person_id, and assigned to exactly one split. The quality analyzer already rejects person leakage, but it consumes derived JSONL rather than owning the source-image manifest contract.

## Manifest contract
Each JSONL row must contain:
- `image_id`: globally unique stable identifier
- `path`: relative path under the declared dataset root
- `person_id`: stable project identity label
- `split`: `calibration`, `validation`, or `locked_test`
- `camera_id`: capture source identifier
- `condition`: controlled condition label
- `authorization_ref`: non-sensitive reference to the consent/authorization record
- `sha256`: SHA-256 of the exact image bytes

No raw biometric/consent details are stored in the repository manifest.

## Verification
The validator must fail closed for:
- duplicate image_id
- duplicate path
- missing files
- path traversal / absolute paths
- invalid split
- empty person_id
- empty authorization_ref
- SHA-256 mismatch
- the same person_id appearing in multiple splits

The validator must emit a deterministic dataset receipt containing manifest SHA-256, image count, person count, split counts, and per-split person counts.

## Acceptance
- Validator has unit tests for all fail-closed cases.
- A real authorized manifest can be validated without modifying source images.
- Dataset receipt is generated before P0.2.2 SCRFD inference.
- No threshold is calibrated by this task.

## Next
P0.2.2 execution: run the verified SCRFD artifact over the validated manifest and produce quality-observation JSONL. Do not tune recognition thresholds or use locked-test observations for calibration.
