# P0.1.3 — Recognition model provenance + license gate

## Status
ACTIVE — technical baseline retained, production model blocked pending artifact/license verification.

## Objective
Lock every SCRFD/ArcFace recognition artifact by exact source revision, file SHA-256, model I/O contract, and separate code/weight license evidence before benchmark or deployment.

## Research finding (2026-09-10)
Official InsightFace currently states that its code is MIT, while supplied pretrained models/training data are non-commercial research only; the current upstream README also directs users to contact InsightFace for licensing of open-sourced recognition models such as buffalo_l. Therefore MIT code licensing must not be treated as a commercial license for pretrained weights.

## Current architectural decision
Keep SCRFD + ArcFace as the technical baseline. Do NOT replace it merely because of licensing. Licensing is a release/provenance gate, not a model-quality benchmark result.

## Required manifest fields
- publisher / upstream repository
- exact commit/tag/release
- artifact filename
- SHA-256
- model family and variant
- input shape / dtype / layout / color order
- preprocessing / normalization
- output shape / embedding dimension
- code license
- weight license
- commercial-use status
- redistribution status
- local-only restrictions

## Verification
1. Fetch exact upstream source/release.
2. Record exact artifact identity.
3. Compute SHA-256 from the actual binary; never invent a digest.
4. Capture license evidence for code and weights separately.
5. Reject deployment if provenance, hash, or commercial-use status is unknown.
6. Only after the gate passes, run recognition accuracy/latency benchmarks.

## Acceptance criteria
- [ ] Exact SCRFD artifact pinned.
- [ ] Exact ArcFace artifact pinned.
- [ ] SHA-256 verified for both.
- [ ] I/O contract verified from graph/source.
- [ ] Weight-license evidence stored.
- [ ] Commercial-use decision recorded.
- [ ] Model registry refuses unapproved artifacts.
- [ ] Benchmark can emit a reproducible model manifest.

## Next step
Implement a fail-closed recognition model manifest verifier, then connect it to the existing FastAPI model registry. After that, execute the real-model benchmark only with an approved artifact.
