# P0.4.12 — Dependency-aware FastAPI readiness

## Objective
Expose a fail-closed `/readyz` contract that reports required recognition dependencies independently and returns HTTP 503 until every required dependency is explicitly verified.

## Required dependencies
- SCRFD
- ArcFace
- alignment
- anti-spoofing (FAS)
- vector database
- model provenance

## Verification
- unit-test the gate with one dependency missing;
- verify all dependencies are required before `ready=true`;
- verify unknown dependency names are rejected;
- verify `/readyz` returns 503 while the current real-model pipeline is unavailable;
- never infer vector DB health merely from construction of a client object.

## Current implementation
`src/api/readiness.py` and `/readyz` in `src/api/main.py`.
`VECTOR_DB_READY=1` is an explicit temporary verification signal; it is not a substitute for a real PostgreSQL/pgvector health query.

## Completion criteria
PASS only with CI execution receipt plus a real dependency probe for production model assets and PostgreSQL/pgvector. Until then status remains IMPLEMENTED / EXECUTION PENDING.
