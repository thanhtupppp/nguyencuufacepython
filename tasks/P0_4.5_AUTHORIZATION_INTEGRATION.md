# P0.4.5 — FAS / identity authorization integration

## Status
IMPLEMENTED — execution receipt pending.

## Objective
Integrate the temporal FAS gate and temporal identity confirmation into one deterministic, fail-closed authorization boundary. A `person_id` may be emitted for an action only when both gates are confirmed for the same camera-local `track_id`.

## Scope
- `src/fas/identity_authorizer.py`
- `tests/test_identity_authorizer.py`
- no model inference
- no recognition threshold changes

## Contract
```text
SCRFD -> track_id
          |-> FAS -> TemporalFasGate
          |-> ArcFace -> vector retrieval -> identity confirmation
                    \\              /
                     -> authorization -> action
```

Rules:
1. FAS never assigns `person_id`.
2. Candidate identity is never authorized.
3. `LIVE_CONFIRMED` with no confirmed identity is blocked.
4. `track_id` mismatch is always blocked.
5. SPOOF/ERROR/UNVERIFIED is blocked.
6. The event is deterministic and contains `camera_id`, `track_id`, optional `person_id`, state and reason.
