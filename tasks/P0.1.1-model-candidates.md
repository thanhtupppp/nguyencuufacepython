# P0.1.1 — Model candidate and license gate

## Status
BLOCKED FOR PRODUCTION — research shortlist complete; no InsightFace pretrained artifact currently has verified production/commercial rights in this repository.

## Latest checkpoint — 2026-09-09
The repository is metadata-first for model artifacts. Commit `22c7d1f` adds `models/README.md` defining the reproducibility/license contract. No pretrained weights have been committed because official InsightFace documentation states that supplied pretrained models/training data are for non-commercial research and that open-sourced recognition model packs such as `buffalo_l` require licensing contact.

Fresh official evidence also records `antelopev2` as non-commercial in its model license metadata.

## Objective
Create a reproducible shortlist of detector/recognizer model artifacts that can be evaluated on real images without silently assuming that repository code licensing also covers pretrained weights.

## Candidates
### A — InsightFace buffalo_l
- Detector: SCRFD det_10g
- Recognizer: ArcFace ResNet50, 512-D
- Status: RESEARCH ONLY until explicit production/commercial licensing is verified.

### B — InsightFace antelopev2
- Detector: SCRFD det_10g
- Recognizer: ArcFace ResNet100, 512-D
- Status: RESEARCH ONLY until explicit production/commercial licensing is verified.

### C — OpenCV Zoo YuNet + SFace
- Status: promoted to the next execution task in `tasks/P0.1.2-commercial-model-benchmark.md` because its model licensing is substantially cleaner for production evaluation.
- This is an alternative benchmark candidate, not an architecture replacement.

## Required checks
1. Record exact artifact URL/source, release/version and SHA256.
2. Record model license/usage rights separately from source-code license.
3. Verify detector landmarks and coordinate convention.
4. Verify recognizer input, channel order, normalization and output dimension.
5. Verify L2-normalized embedding behavior.
6. Run real-image smoke test with identical preprocessing.
7. Record PC CPU latency, peak memory and cold/warm inference latency.
8. Identify Raspberry Pi/Android deployment path using the same ONNX contract where possible.
9. Do not use synthetic vectors for identity-threshold calibration.

## Completion criteria
- Production license status is explicit for every shortlisted artifact.
- At least one candidate can be evaluated under the intended deployment rights.
- Preprocessing/alignment contract is reproducible.
- Any architecture change is supported by the same real-image benchmark protocol.
