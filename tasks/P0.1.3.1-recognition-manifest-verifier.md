# P0.1.3.1 — Recognition model manifest verifier

## Mục tiêu
Fail-closed provenance gate cho SCRFD + ArcFace trước khi model được đăng ký hoặc chạy qua FastAPI.

## Contract
Mỗi artifact phải khai báo:
- model_id
- publisher/upstream URL
- exact revision/tag
- local filename/path
- SHA-256
- input/output contract
- embedding dimension (ArcFace: 512D nếu artifact được xác minh)
- code license
- weight license
- commercial-use status
- redistribution status

## Verification
1. Parse manifest.
2. Require non-placeholder SHA-256.
3. Hash artifact bytes và so khớp SHA-256.
4. Reject missing/unknown license evidence.
5. Reject missing I/O contract.
6. Emit deterministic verification receipt.

## Acceptance
- Placeholder SHA => FAIL.
- Missing artifact => FAIL.
- SHA mismatch => FAIL.
- Missing weight-license evidence => FAIL.
- Contract mismatch => FAIL.
- Only a fully verified artifact may reach the model registry.

## FastAPI integration boundary
Model registry must call this verifier before loading/serving an artifact. Runtime remains fail-closed when no approved recognition model is available.
