# P0.4.2 — FAS artifact verification and inference contract

## Objective
Turn the anti-spoof candidates into benchmarkable, reproducible inputs without approving a model prematurely.

## Scope
For each candidate in `configs/fas_artifacts.yaml`:

1. obtain the exact artifact bytes from the pinned upstream revision;
2. record SHA-256;
3. verify the applicable weight/model license and provenance;
4. inspect ONNX graph input/output names, shapes, dtypes and operators;
5. reproduce the upstream preprocessing/postprocessing contract;
6. create a deterministic inference receipt on the same face-crop fixtures;
7. reject the candidate if any contract field remains unresolved.

## Candidates
- `facenox_minifasv2se_int8`: edge challenger, pinned to commit `fa6489fb221dcf6b803095ab4b15a0fa0f56cfe5`.
- `yakhyo_minifasv2`: reproducible reference, pinned to commit `aea85c1fa14e4d52a7910af75d59ef51e62a2267`.

The second candidate's repository is Apache-2.0 licensed, but the project will not infer that the downloaded weights inherit the same license until the weight provenance is explicitly verified.

## Acceptance
- immutable upstream revision;
- verified SHA-256;
- explicit weight-license evidence;
- ONNX graph contract captured;
- deterministic preprocessing and score direction;
- `tools/verify_fas_manifest.py` passes;
- `tools/validate_fas_candidate_manifest.py` passes;
- no placeholder fields remain for the candidate being benchmarked.

## Non-goals
This task does not establish APCER/BPCER/ACER and does not select the production FAS model. Those require P0.4.1 benchmark execution on a locked evaluation protocol.
