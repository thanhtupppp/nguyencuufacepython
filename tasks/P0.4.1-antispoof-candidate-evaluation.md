# P0.4.1 — Anti-spoofing candidate evaluation

## Goal
Select an anti-spoofing model for the biometric gate without changing the recognition architecture until an apples-to-apples edge benchmark is available.

## Candidates
1. MiniFASNetV2/V2-SE from Minivision Silent-Face-Anti-Spoofing.
2. A lightweight MiniFASNetV2-SE ONNX implementation suitable for ARM/ONNX Runtime.
3. A stronger compact FAS candidate from the CVPR 2024 efficient-FAS work (MN3-small/large family) as a research challenger, subject to model/license availability.

## Why
CelebA-Spoof is large (625,537 images, 10,177 subjects) and includes multiple spoof types, environments and sensors, but published cross-dataset results show that high CelebA-Spoof performance does not guarantee robustness on another dataset. Therefore accuracy on one dataset must not be the architecture-selection criterion.

## Evaluation protocol
- Same SCRFD detection and same 5-point alignment before every FAS model.
- Evaluate live vs print, screen replay and mask/replay categories where available.
- Report APCER, BPCER, ACER, ROC-AUC/EER and latency p50/p95 on x86 and ARM64.
- Measure false-reject impact on genuine recognition separately from false-accept spoof risk.
- Test temporal aggregation on tracked faces; do not average raw frame scores across unrelated tracks.
- Keep an untouched local/device test set for final acceptance.

## Architecture gate
Do not replace MiniFASNet with a larger model solely because of headline benchmark accuracy. A challenger must improve security metrics at the target operating point while meeting edge latency/memory and license requirements.

## Acceptance criteria
- Reproducible model artifact and license recorded.
- Identical preprocessing/alignment across candidates.
- APCER/BPCER/ACER and latency receipts generated.
- Cross-dataset or local held-out test included.
- Decision documented as KEEP / REPLACE / TWO-TIER, with evidence.

## Current status
ACTIVE — research/design gate only. No candidate is promoted until benchmark evidence exists.

## Next
