# P0.4.1.1.1 — FAS model I/O contract verification

## Objective

Remove hard-coded assumptions from the anti-spoof benchmark before any quality result is accepted. Each model artifact must have a verified input/output contract and SHA-256 before execution.

## Evidence reviewed

- `facenox/face-antispoof-onnx` documents 128x128 RGB MiniFAS input and a two-class Real/Spoof classifier. Its demo uses `process_with_logits` and a configurable threshold, so the project must not guess whether output[1] is a probability or a logit without inspecting the actual exported model and inference code.
- `yakhyo/face-anti-spoofing` documents MiniFASNetV1SE/V2 ONNX inference and a V2 crop scale of 2.7.

## Implementation

`tools/evaluate_fas.py` now reads verified `input` and `output` semantics from `configs/fas_artifacts.yaml` instead of hard-coding float32, `/255`, output index 1, or score direction.

The evaluator fails closed for unresolved fields such as `REQUIRES_VERIFICATION` or `IMPLEMENTATION_*`.

## Verification protocol

For every candidate:

1. Obtain the exact upstream artifact and revision.
2. Compute SHA-256 locally and record it in the manifest.
3. Inspect ONNX graph input name, shape, dtype and output shape.
4. Verify preprocessing against the candidate's reference inference implementation.
5. Verify output semantics: logits vs probability, class index mapping, and score direction.
6. Verify the face crop/alignment contract separately; do not use a plain full-image resize as a production result.
7. Only then run the common benchmark.

## Completion criteria

- SHA-256 verified.
- Weight license verified separately from source-code license.
- Input contract verified.
- Output contract verified.
- Crop/alignment contract verified.
- Evaluator runs without any unresolved manifest fields.
- Benchmark receipt contains the exact artifact digest and I/O contract.

## Current status

ACTIVE — the repository has the fail-closed evaluator, but the actual model artifact bytes, SHA-256, weight license, and project-aligned preprocessing are not yet verified.
