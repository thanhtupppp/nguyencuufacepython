# P0.4.22 — Real model artifact + inference smoke test

## Objective
Lock the actual SCRFD/ArcFace artifacts by model ID, version, SHA-256, source and license/provenance before using embeddings for scientific retrieval benchmarks.

## Verification
1. Manifest contains all provenance fields.
2. Artifact exists and SHA-256 matches.
3. ONNX Runtime loads the artifact on the supported CPU baseline.
4. ArcFace input is 112x112 and output is 512-D.
5. Embeddings are finite and L2-normalized.
6. Record a reproducible inference receipt: model ID/version/SHA, runtime/provider, input contract and output contract.

## Completion criteria
- No placeholder provenance values remain for the locked artifact.
- SHA-256 verification passes.
- Real inference smoke test passes.
- License/provenance is explicitly reviewed before deployment.
- CI receipt exists for the tests.

## Architecture rule
Do not replace SCRFD/ArcFace based on availability or speed. Any alternative model must first pass the same benchmark and provenance gate.
