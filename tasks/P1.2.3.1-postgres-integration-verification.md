# P1.2.3.1 — PostgreSQL integration verification

Status: ACTIVE — integration tests added; runtime execution pending

## Objective
Prove that durable RecognitionEvent idempotency works against a real PostgreSQL instance, including application restart semantics and concurrent duplicate inserts.

## Implemented
- Added `tests/test_postgres_event_repository_integration.py`.
- Test creates the required `recognition_events` table when running against a disposable integration database.
- Test verifies a duplicate event_id returns the original payload and never overwrites it.
- Test verifies eight concurrent inserts converge to exactly one stored row and one accepted result.

## How to verify
1. Start PostgreSQL from `docker-compose.yml` with `POSTGRES_PASSWORD` set.
2. Set `DATABASE_URL` to that PostgreSQL instance.
3. Run `pytest -q tests/test_postgres_event_repository_integration.py`.
4. Restart/recreate the API process and repeat the duplicate assertion against the same database.
