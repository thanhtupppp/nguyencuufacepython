# P0.1.3.2 — FastAPI recognition model registry

## Mục tiêu
Nối provenance/sha/license verifier vào runtime boundary của FastAPI để model SCRFD/ArcFace chưa được phê duyệt không thể được coi là production-ready.

## Implementation
- `app/model_registry.py` owns manifest verification and approval state.
- `RECOGNITION_MODEL_MANIFEST` selects the manifest in production.
- Startup attempts approval; verification failure leaves registry blocked.
- `/v1/models/status` reports `503` while blocked and `200` only after approval.
- `/healthz` reports recognition model state without pretending recognition is available.

## Verification
1. Missing manifest => registry cannot approve.
2. Placeholder SHA => registry blocked.
3. Missing artifact => registry blocked.
4. Unknown/unverified weight license => registry blocked.
5. SHA mismatch => registry blocked.
6. Only a fully verified manifest may reach `approved=True`.

## Acceptance
- Runtime never loads/serves an unapproved recognition artifact.
- Status endpoint exposes the blocked state deterministically.
- Real authorized SCRFD + ArcFace artifacts can be integrated without changing the registry contract.
