# P0.4.1.1 — Reproducible anti-spoof artifact pinning

## Goal
Pin reproducible anti-spoof model artifacts before implementing the common benchmark harness. Do not promote or replace the FAS architecture from headline accuracy alone.

## Current candidates
1. MiniFASNetV2/V2-SE from Silent-Face-Anti-Spoofing lineage.
2. `yakhyo/face-anti-spoofing` ONNX/PyTorch implementation as a reproducible reference implementation.
3. `facenox/face-antispoof-onnx` MiniFASNetV2-SE ONNX/INT8 as an edge challenger/reference artifact.
4. Efficient-FAS MN3-small/large remains research-only until a redistributable artifact and license are verified.

## Pinning requirements
For every candidate record:
- exact upstream repository URL and commit/tag;
- exact model filename;
- SHA-256 of downloaded artifact;
- input size, channel order, normalization and crop/alignment procedure;
- output semantics and score direction;
- license for code and model weights separately;
- source dataset/evaluation protocol when claims are quoted.

## Reproducibility rule
Do not copy model weights into the repository unless licensing explicitly permits it. Prefer a manifest with URL, revision, SHA-256 and license metadata. Benchmark scripts must fail closed when a hash does not match.

## Acceptance criteria
- At least one MiniFASNet artifact is pinned with a verified SHA-256.
- Preprocessing is captured in the manifest.
- License is recorded separately for implementation and weights.
- Benchmark harness can resolve the artifact without changing model code.
- No architecture decision is made from upstream accuracy claims alone.
