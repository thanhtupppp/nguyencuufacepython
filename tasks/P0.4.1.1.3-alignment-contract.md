# P0.4.1.1.3 — SCRFD landmarks → ArcFace canonical crop

Status: IMPLEMENTED_BASELINE

## Objective

Lock the face-crop contract shared by recognition and anti-spoof benchmarking:

`SCRFD 5 landmarks → similarity transform → 112x112 canonical crop`.

The canonical five points are the values used by the official InsightFace
`python-package/insightface/utils/face_align.py` at the pinned upstream revision.

## Verification

- Unit test the canonical template values.
- Identity landmark input must produce an identity transform.
- Invalid landmark shape must fail closed.
- Next gate: integration test with real SCRFD landmarks and a known image fixture.
- Next FAS gate: compare BGR-vs-RGB caller channel order on the same aligned crops;
  do not assume README color wording is sufficient.

## Repository/model references

- Recognition baseline: InsightFace SCRFD + ArcFace.
- Alignment reference: official InsightFace `face_align.py`.
- Local implementation: `src/alignment/arcface.py`.

## Acceptance criteria

1. Exactly five 2D landmarks are required.
2. Landmark order is left eye, right eye, nose, left mouth, right mouth.
3. Output is exactly 112x112 for the ArcFace baseline.
4. The transform is similarity/partial affine, not an unconstrained perspective warp.
5. Alignment is deterministic and versioned as part of the recognition model contract.
6. No production FAS benchmark is accepted until the same alignment/crop contract is used.
