# P0.1.2 — YuNet + SFace model A/B protocol

## Status
ACTIVE — implementation contract ready; empirical run is blocked only on evaluation images/model artifacts.

## Purpose
Benchmark OpenCV Zoo YuNet + SFace against the project's SCRFD + ArcFace reference without changing the architecture prematurely.

## Model artifacts
- Detector: `face_detection_yunet_2023mar.onnx` (pin exact release URL + SHA256 before use)
- Recognizer: `face_recognition_sface_2021dec.onnx` (pin exact release URL + SHA256 before use)
- Do not commit weights to git unless redistribution rights are explicitly verified.

## Fixed pipeline
1. Decode image without hidden resize/crop.
2. Detect face.
3. Require compatible 5-point landmarks.
4. Apply the repository's canonical similarity/Umeyama alignment to 112x112.
5. Run recognizer.
6. L2-normalize output embedding.
7. Evaluate genuine and impostor pairs using the same pair manifest for every model.

## Metrics
### Detection
- face detection success rate by face-size bucket
- missed-face rate
- false detections/frame

### Recognition
- top-1 identification accuracy
- TAR at FAR 1e-2, 1e-3, 1e-4 when sample count supports it
- FMR/FNMR
- ROC/DET
- EER
- genuine/impostor score distributions
- top1-top2 margin distributions

### Runtime
- cold-start latency
- warm p50/p95/p99
- peak RSS
- model size
- ONNX Runtime/OpenCV backend metadata

## Required slices
- normal light
- low light
- yaw/pitch variation
- blur
- partial occlusion
- small faces
- multiple faces/frame
- different cameras

## Rules
- Same people, same enrollment/query split, same alignment policy, same pair manifest.
- Thresholds are calibrated only on validation data and evaluated once on locked test data.
- Never tune a threshold to compensate for detector failures or vector-retrieval misses.
- Do not compare headline paper accuracy directly with this project benchmark.
- Keep model version in every result row.

## Decision gate
Adopt YuNet + SFace only if it has explicit usable licensing AND meets the project's false-match target while providing a material deployment advantage. Otherwise retain SCRFD + ArcFace as the accuracy reference and continue with the next task.

## Current evidence
OpenCV Zoo documents YuNet as a lightweight detector and SFace as a 5-landmark-compatible recognizer. SFace's model card reports its own evaluation scores, but those scores are not sufficient for this project's architecture decision.
